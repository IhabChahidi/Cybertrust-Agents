# --- Non-Python prerequisites (not installable via pip -- see README.md) ---
# - llama.cpp itself: https://github.com/ggml-org/llama.cpp
#     Either a prebuilt release binary (github.com/ggml-org/llama.cpp/releases)
#     or built from source, which additionally requires:
#       - CMake            (winget install --id Kitware.CMake -e)
#       - A C++ compiler   (winget install --id Microsoft.VisualStudio.2022.BuildTools -e
#                            --override "--add Microsoft.VisualStudio.Workload.VCTools --includeRecommended")
# - The GGUF model file itself (several GB) -- never downloaded automatically
#   by this repo's code (docker-compose.yml, scripts/); must be fetched
#   explicitly and placed under ./models/.
